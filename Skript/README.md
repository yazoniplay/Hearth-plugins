# CloudSMP Skript Weapons

## Install
1. Make sure the server runs Paper 1.21.11 and has Skript installed.
2. Upload `CloudSMPWeapons.sk` to `plugins/Skript/scripts/CloudSMPWeapons.sk`.
3. In-game or in console, run `/sk reload CloudSMPWeapons`.
4. Players can run `/weapons` to open the weapon vault.
5. Operators can run `/cloudweapon mace`, `/cloudweapon crossbow`, `/cloudweapon bow`, `/cloudweapon axe`, or `/cloudweapon trident` to test individual items.

The script is intended for a recent Skript release. Test it on a staging server before using it on a live server, as Skript syntax and projectile event behavior can vary by version.

Explosive arrows are implemented as entity-only damage; the script does not intentionally create block-damaging explosions.
