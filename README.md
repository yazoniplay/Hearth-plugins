# 🔥 Hearth SMP

A custom-built cozy Minecraft SMP ecosystem for Java + Bedrock.

## Vision

Hearth is a public survival server built around cozy building, community, economy, claims, seasons, and lightweight lore.

## Development principles

- Custom systems first; avoid unnecessary gameplay plugins.
- Clean, cozy Minecraft-native GUIs.
- No excessive gradients, glow, or clutter.
- Shared UI patterns across every Hearth system.
- Java 21 + Gradle + Paper API.
- GitHub Actions builds the plugins.
